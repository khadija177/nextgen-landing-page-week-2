# NextGen Learners - Week 2 Landing Page

## 📌 Project Overview
This project was completed as part of the NextGen Learners Web Development Internship (Week 2).

The project is a responsive landing page with JavaScript functionality, including a mobile navigation menu, internship application form, form validation, and local storage.

## ✨ Features
- Responsive Landing Page
- Mobile Hamburger Menu
- Internship Application Form
- JavaScript Form Validation
- Success Message on Submission
- Local Storage Integration
- My Submissions Section

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
